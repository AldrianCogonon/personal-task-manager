# Personal Task Manager

A simple, lightweight personal task manager built with Laravel, PHP, and MariaDB for managing daily tasks and assignments.

---

## Features
* **ADD TASK**
* **VIEW TASKS**
* **EDIT TASK**
* **DELETE TASK**
* **UPDATE STATUS** 
* **SEARCH BAR**
* **DARK/LIGHT MODE**
---

## Tech Stack
* **Backend:** PHP / Laravel
* **Database:** MariaDB
* **Frontend:** HTML, CSS (Blade Views)
* **OS Environment:** Arch Linux
